# 分批分析与恢复

仅在用户要分析、整理或继续分析时使用。用户当前问题可以直接从原文检索回答，无需等待全书预分析。

## 领取、阅读、提交

以下命令统一加上已确认的解释器、脚本绝对路径和 `--workspace "<小说目录>"`。

```text
status
task next
task next --chapter-from 2 --chapter-to 4
task submit "<小说目录>/.novel/inbox/analysis.json"
```

CLI 返回 `{"ok": true, "result": …}`；`task next` 的 `result.state` 为 `pending` 时，任务包在 `result.task`，内含 `task_id`、`input_fingerprint`、`source_revision`、章节信息和允许引用的片段。每个片段含工具发放的 ID 与文本。原样保留任务 ID 和输入指纹；分析实际提供的范围，不凭记忆补全后章信息。超长章节可拆成多项任务，完成一项不等于整章完成。

先检查结果是否截断和是否有继续读取提示。无法取得完整任务输入时不要提交“完整分析”。少量相邻上下文用于理解当前材料，不把全书旧摘要递归当作本次原文。

模型写入的 JSON 结构为：

```json
{
  "task_id": "从任务包复制",
  "input_fingerprint": "从任务包复制",
  "overview": "仅概括本任务范围的简短导航。",
  "mentions": [
    {
      "name": "沈砚",
      "evidence": [{"span_id": "从任务包复制", "quote": "该片段内准确且足以定位的原句"}]
    }
  ],
  "claims": [
    {
      "kind": "belief",
      "text": "沈砚此时只是怀疑，尚未确认。",
      "evidence": [{"span_id": "从任务包复制", "quote": "支持该判断的准确原句"}]
    }
  ],
  "open_questions": [
    {
      "text": "当前材料尚不能确定的疑问。",
      "evidence": [{"span_id": "从任务包复制", "quote": "触发疑问的准确原句"}]
    }
  ]
}
```

示例中的 ID 与引文说明文字必须替换为本次任务真实返回的数据。没有适用条目时使用空数组，不为凑数编造人物、事件或疑问。`open_questions` 的 `evidence` 可省略；需要复用的事实型主张必须有证据。

`claims.kind` 的含义如下：

| 值 | 用途 |
| --- | --- |
| `narration` | 叙述文本呈现的事件或状态 |
| `speech` | 某角色说了什么；不代表说法属实 |
| `belief` | 角色的怀疑、相信、知道等认知状态，保持原文强度 |
| `inference` | 研究者从材料作出的推断 |
| `interpretation` | 可与其他读法并存的文学解释 |
| `unknown` | 当前不能确定，需保留歧义 |

同名和称谓只记录出现，不自动合并身份。事件发生与事件因果分开；身份、指代、动机或伏笔需要跨章核实的，保留为问题，留给后续研究。概览只作导航，不能当作正式原文证据。

## 成功、失败与断点

调用 `task submit` 后读取返回结果；只有接收成功才算完成。程序校验结构、任务指纹和引用，生成正式 ID 与位置；模型不填位置、哈希、校验结果或虚构的模型标识。校验通过仍不代表主张语义正确。

收到引文歧义时，扩大为同一片段内唯一的连续原句。未知片段、错版或过期输入应重新领取任务；不能复制旧 ID 伪装成当前任务。一般格式问题最多修复两次，继续失败则保留草稿和诊断，报告该任务未完成。

提交成功后继续领取下一项，直到用户指定范围完成、用户要求停止或宿主资源限制需要结束。结束时用 `status` 报告已完成、未完成、失败和过期情况；覆盖完成只表示指定输入处理过，不能说已经找全所有伏笔。

已接收的相同结果可以重试，工具应返回已有记录；同一任务的不同结果会报冲突，不覆盖旧记录。修正已接受内容请保存关联纠错，不能直接编辑记录文件。

新会话重新运行 `status`、`notes recall` 和 `task next` 即可恢复；inbox 草稿和历史聊天不是完成依据。保存阶段检查点时记录本次范围、未决问题及下一步。正文更新先 `prepare`，再 `check`，按当前任务继续，旧记录仍绑定旧快照。
